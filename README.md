# Microsoft 365 User Reporting Tool | PowerShell

Microsoft 365 User Reporting Tool is a PowerShell-based administration and reporting tool that leverages Microsoft Graph API to retrieve, analyze and export user information from Microsoft 365 environments.

## Features

- List All Users
- Search Users
- User Details Lookup
- User Statistics
- CSV Report Export
- Tenant Information
- Microsoft Graph Integration
- Error Handling with Try/Catch

## Technologies Used

- PowerShell
- Microsoft Graph
- Get-MgUser
- Get-MgOrganization
- Where-Object
- Select-Object
- Export-Csv
